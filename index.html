Project 01 · Jun 2026 – Present · In progress

Autonomous Payload Quadcopter

A self-built F450-frame quadcopter designed to carry and release a liquid payload with no operator input, splitting flight control and vision processing across two computers.

  1. Paired a Pixhawk 6C flight controller with a Raspberry Pi companion computer so vision workloads never compete with the flight-control loop.
  2. Designed a MOSFET switching circuit (IRF520 driver) to actuate a water-pump payload from GPIO, isolating logic signals from pump inrush current.
  3. Built the power distribution around a 5V UBEC, separating the logic rail from high-current ESC loads for stability under full throttle.
  4. Currently integrating an M10 GPS module for waypoint navigation and an OpenCV pipeline for autonomous target tracking.
  • Pixhawk
  • Raspberry Pi
  • OpenCV
  • Power electronics
  • Embedded systems

Project 02 · Nov 2026 · Simulation

PX4 SITL Experiments

Testing the quadcopter's flight software in software-in-the-loop simulation before trusting it on real hardware: PX4 built from source, a simulated quad in Gazebo, and QGroundControl as the ground station.

  1. Cut the ground-station link mid-hover and confirmed PX4's staged response: hold for a 5 s grace period, then return to launch and land.
  2. Injected a GPS failure in flight. With no position estimate, PX4 fell back to a blind landing in place and finished it even after GPS returned.
  3. Wrote a Python MAVLink script (pymavlink) that arms, takes off to 2.5 m, streams altitude and lands, checking each command's acknowledgement.
  4. Fixed two bugs in it: takeoff was sent before arming was confirmed, and altitude readings lagged behind an unread message queue.
  • PX4
  • MAVLink
  • Python
  • Gazebo
  • SITL
  • Linux (WSL2)
