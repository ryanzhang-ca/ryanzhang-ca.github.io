PROJECTS

Autonomous Payload Quadcopter

Jun 2026 – Present · Independent build

A self-built F450-frame quadcopter designed to carry and release a liquid payload with no operator input. The build splits work across three domains: a Pixhawk 6C handles low-level flight control while a Raspberry Pi companion computer takes on vision and payload logic, keeping camera and detection workloads off the flight-control loop.

  • Paired a Pixhawk 6C flight controller with a Raspberry Pi companion computer so vision processing never competes with the flight-control loop for cycles.
  • Designed a MOSFET switching circuit (IRF520 driver) to actuate a water-pump payload from Pi GPIO, isolating logic-level signals from pump inrush current to prevent brownouts on the companion computer.
  • Built the power distribution scheme around a 5V UBEC, separating the logic rail from high-current ESC loads so onboard electronics stay stable through full-throttle draw.
  • In progress: M10 GPS integration for Pixhawk waypoint navigation, plus an OpenCV detection pipeline on the Pi for autonomous target tracking and payload release.
